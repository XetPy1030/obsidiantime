Какие данные мы собираем

С вашего согласия мы сохраняем на своём сервере сведения о посещении: IP-адрес, данные браузера и устройства (модель, ОС, экран, язык, часовой пояс, видеокарта, тип подключения), открытые страницы и откуда вы пришли, время на странице, прокрутку и клики по ссылкам и кнопкам. {% if analytics and analytics.is_active %} Также подключаются сторонние счётчики {% if analytics.yandex_metrika_id %}Яндекс.Метрика{% endif %} {% if analytics.google_analytics_id %}Google Analytics{% endif %} {% if analytics.facebook_pixel %}Facebook Pixel{% endif %} {% if analytics.vk_pixel %}VK Pixel{% endif %}. {% endif %} Текст, который вы вводите, и пароли мы не собираем.

Без согласия сайт работает так же. Изменить решение, посмотреть или удалить свои данные можно в любой момент на странице «Конфиденциальность».
